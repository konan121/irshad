# الركن الإرشادي

موقع سلسلة فيديوهات «الركن الإرشادي» لمدرسة رياض الأزهار للبنات (٥–٩).

إعداد الأخصائيتين الاجتماعيتين: هاجر الذهلي · كوثر العجمي

**رابط الموقع:** https://konan121.github.io/irshad/

#نحو_سلوك_مدرسي_إيجابي

## إضافة حلقة جديدة (الطريقة المختصرة)

١. ارفع الفيديو وصورة الغلاف إلى مجلد Drive العام، واجعل مشاركتهما «أي شخص لديه الرابط».

٢. افتح الطرفية داخل مجلد المشروع وشغّل:

</div>

```bash
npm run add-episode
```

<div dir="rtl">

٣. أجب عن الأسئلة: العنوان، والقالب، والمدة، والتاريخ، والملخص، ورابط الفيديو، ورابط الغلاف. في النهاية اختر «ن» ليُرفع الموقع. تظهر الحلقة على الرابط خلال دقيقتين تقريبًا.

---

## إضافة حلقة جديدة (خطوة خطوة)

### قبل البدء (مرة واحدة فقط على الجهاز)

- ثبّت Node.js الإصدار ٢٤ أو أحدث.
- نزّل المشروع وثبّت مكتباته:

</div>

```bash
git clone https://github.com/konan121/irshad.git
cd irshad
npm install
```

<div dir="rtl">

- سجّل الدخول إلى GitHub مرة واحدة (يفتح المتصفح لتأكيد الدخول):

</div>

```bash
~/.local/bin/gh auth login -h github.com -p https -w -s workflow
```

<div dir="rtl">

### الخطوة ١: جهّز الملفات في Drive

- ارفع الفيديو بجودة 1080p إلى مجلد السلسلة في Drive.
- ارفع صورة الغلاف. الأفضل أن تكون بمقاس **1280×720** أو أكبر لتظهر واضحة في الموقع وفي معاينة واتساب.
- لكلا الملفين: زر «مشاركة» ← «أي شخص لديه الرابط» ← «نسخ الرابط».

### الخطوة ٢: شغّل سكربت الإضافة

</div>

```bash
npm run add-episode
```

<div dir="rtl">

سيسألك السكربت بالترتيب:

| السؤال | مثال |
|---|---|
| عنوان الحلقة | السلّةُ الجائعة! |
| رقم القالب | `5` لقالب «توعوي»، أو `1,4` لقالب «موقف وحلّ ← مهارة اليوم» |
| المدة | `2:33` |
| تاريخ النشر | اضغط Enter لتاريخ اليوم، أو اكتب `2026-11-08` |
| الملخص | جملتان أو ثلاث تصف الحلقة |
| رابط الفيديو | الرابط المنسوخ من Drive |
| رابط الغلاف | الرابط المنسوخ من Drive |

ثم يقوم السكربت تلقائيًا بما يلي:

- يتأكد أن الفيديو والغلاف متاحان للعامة.
- يحفظ الحلقة في `src/data/episodes.json`.
- ينزّل الغلاف ويجهّز منه نسخًا خفيفة للموقع وصورة معاينة لواتساب.
- يبني الموقع ليتأكد أن كل شيء سليم.
- يسألك: «هل أرفع الحلقة إلى الموقع الآن؟» اختر **ن**.

### الخطوة ٣: تأكد من ظهورها

بعد دقيقتين تقريبًا افتح الرابط الذي يطبعه السكربت، مثل:
`https://konan121.github.io/irshad/ep/ir09/`

يمكنك متابعة النشر من تبويب **Actions** في صفحة المستودع على GitHub.

## نشر حلقة محفوظة كمسودة

الحلقة التي حالتها `"draft": true` في `episodes.json` لا تظهر في الموقع. عند تشغيل `npm run add-episode` سيسألك السكربت أولًا إن كنت تريد نشر المسودة، ويقترح بياناتها المحفوظة، فتضغط Enter لقبولها وتضيف رابطي Drive فقط.

## تعديل حلقة موجودة

افتح `src/data/episodes.json` وعدّل العنوان أو الملخص مباشرة، ثم:

</div>

```bash
git add src/data/episodes.json
git commit -m "تعديل بيانات حلقة"
git push
```

<div dir="rtl">

إذا غيّرت صورة الغلاف فاحذف صورها القديمة من `public/img/posters` و`public/img/og`، ثم شغّل `npm run assets` قبل الرفع.

## أوامر مفيدة

| الأمر | ماذا يفعل |
|---|---|
| `npm run dev` | يشغّل الموقع على الجهاز للمعاينة: http://localhost:4321/irshad/ |
| `npm run build` | يبني الموقع في مجلد `dist` |
| `npm run assets` | ينزّل الأغلفة والشعارات الناقصة من Drive |
| `npm run check-site -- <الرابط>` | فحص آلي بمقاس iPhone 13 والكمبيوتر |
| `node scripts/make-og-home.mjs` | يعيد توليد صورة معاينة الصفحة الرئيسية |

## كيف يعمل الموقع

- موقع ثابت مبني بإطار **Astro**، بلا خادم ولا قاعدة بيانات.
- عند كل رفع إلى الفرع `main` يبني **GitHub Actions** الموقع وينشره على GitHub Pages تلقائيًا.
- الفيديوهات تبقى في Google Drive. المشغّل يُحمَّل فقط عند الضغط على الغلاف، حفاظًا على سرعة الصفحة على شبكة الجوال.
- الأغلفة والشعارات والخطوط محفوظة داخل الموقع في مجلد `public/`، فلا تعتمد الزيارة على Drive إلا عند تشغيل الفيديو.
- `legacy/index.html` نسخة من الصفحة القديمة للرجوع إليها.

## قواعد المحتوى

- لا يظهر رقم أي حلقة للزائر. المعرّف `ir01…` داخلي فقط.
- الشخصيات متخيَّلة، ولا صور ولا أسماء لطالبات حقيقيات.
- لا رسوم للرموز الوطنية تُضاف إلى الموقع.
